# STRY00144093 — Tela de consulta e Download de arquivo consolidado CNAB no HUB

Fonte: `download consolidado.md`, descrição final e atualização de 23/10/2026 14:38:30. Cópia minimizada sem nomes de colaboradores ou metadados administrativos. A HU anterior é dependência negocial; ID não fornecido.

## Descrição vigente

Deve ter um novo CARD, no qual usuário Matriz pode realizar o download de arquivo retorno consolidado, tanto o 750, quanto o 150.

No CARD: Nome; Tipo; Situação; Data do processamento; Hora do processamento.

Antes do CARD acima deve ter a lista de consolidados do dia selecionado: Tipo de Remessa; Arquivo (onde faz o download); Convênio; Sequencial; Data/hora situação.

O nome do CARD deve ser "Retorno Consolidado".

## Critérios oficiais

CA01 – Tipos de arquivo disponíveis: Dado que existam arquivos de retorno consolidado processados, quando o usuário Matriz visualizar o novo CARD, então deverão ser disponibilizados para download os arquivos CNAB 750 e CNAB 150.

CA02 – Informações apresentadas no CARD: Dado que exista um arquivo de retorno consolidado disponível, quando ele for apresentado no CARD, então deverão ser exibidas as informações Nome do arquivo, Tipo do arquivo, Situação, Data do processamento e Hora do processamento.
